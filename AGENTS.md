# Project guidance

The user wants every future addition to look neat, clean and beautiful, with useful feature improvements.

- Use the shared navy and mint design system in `UiTheme.cs`. Reuse its fonts, colors, rounded buttons, cards and grid styles.
- Keep controls grouped by task. Preserve clear spacing, readable labels, consistent units and a visible primary action.
- Check the layout at a small laptop window size and with Windows display scaling. Avoid clipped buttons, hidden settings and crowded toolbars.
- Add features that solve a clear workflow need. Use the Profiles page for named setups rather than adding unrelated controls to the main screen.
- Keep status and failures readable. Loading settings must leave playback stopped. Preserve infinite looping, focus pausing and emergency stop behavior.
- Build and run the relevant checks, and visually inspect the finished interface before delivery. Be explicit about anything not verified in Roblox.
